# Theme design

- 核心概念：丝网印刷警示海报——暖纸底上洋红 × 黑双色套印，半调网点、45° 排线、斜切警示条纹带和描边大字，把界面做成一张正在印刷中的 CAUTION 工业海报。错版感来自「硬性偏移阴影」（色块与黑版错位 3–6px），而不是模糊投影。
- 复杂程度：表现型
- 语义颜色与字体：
  - 纸底 `--paper` #f5f1e8（暖纸白）
  - 卡面 `--card` #fdfbf7
  - 纸深色 `--paper-deep` #ece5d5
  - 洋红 `--magenta` #e6007e / 深洋红 `--magenta-deep` #a8005c
  - 墨色 `--ink` #17140f、`--ink-soft` #57503f、`--ink-faint` #96897a
  - 字体保持原生；页面级标题（插件页、定时任务页）加 uppercase + 字距，聊天内容不动
- 表面层级：根背景（纸底 + 洋红网点 + 黑色排线斜角）→ 侧栏暖纸实色 + 顶部警示条纹带 + 2px 墨线右边框 → 主内容白卡 + 2px 墨框 + 洋红硬偏移阴影 → 弹层白卡 → 输入框白卡 + 墨框
- 主要材质：半调网点（radial-gradient 程序生成：洋红 20px 网格 + 黑色 9px 细网反向漂移）与 45° 排线（repeating-linear-gradient，仅露在斜切角区）
- 标志性元素：
  1. 侧栏顶部警示条纹带（洋红/黑 45° 斜杠，缓慢横向走带）
  2. 首页右上角 CAUTION 角标（内联 SVG：洋红描边大字 + 错版黑影，下方叠一条纯 CSS 警示条纹带，整体倾斜 -6°，呼吸错版动效）
  3. 全局硬性偏移阴影：按钮、选中项、输入框、用户气泡用 3–6px 实色错位阴影模拟套印不准
- 视觉来源映射：
  - 洋红 × 黑双色 + 半调网点 ← 参考图整体的孔版印刷双色调
  - 警示条纹带与 CAUTION 大字 ← 参考图中央斜穿的 CAUTION 警示带
  - 45° 排线与斜切构图 ← 参考图对角线切分
  - 十字 / 六角工业符号 ← 参考图边角的几何记号
  - 硬偏移阴影 ← 参考图洋红与黑版的套印错位
- 复用范围：只复用 halftone-star 已验证的 token 重映射骨架和选择器结构（侧栏、主面板、输入框、插件页、代码块）；配色、警示带、角标素材、硬偏移阴影体系均为本次原创
- 背景来源：纯 CSS 程序生成 + 内联 SVG data-URI 角标，无位图素材文件
- 动效强度：克制但存在——网点双层漂移（44s / 31s）、警示带走带（9s）、角标呼吸错版（6s）；`prefers-reduced-motion` 下全部停用
- 状态交互：无
- 功能组件：无
- 图片和用户内容如何处理：保持原样（头像、插件图标、用户图片不改）
- 需要覆盖的页面与状态：主页与输入框、会话内容页、用户气泡、代码块、弹层、插件页、定时任务页、侧栏选中/hover、focus-visible、窄窗口、reduced-motion
- 本轮明确不做：暗色模式、rootStateToggle 交互、widget 组件、自定义字体、AI 位图素材、聊天内容排版改造
- 用户确认的设计摘要：表现型；按参考图做洋红+黑工业印刷风，风格大胆；背景用纯 CSS 程序化网点/排线；克制动效带 reduced-motion 降级；无交互无组件
