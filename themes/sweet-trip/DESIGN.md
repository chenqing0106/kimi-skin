# Theme design · sweet-trip

- 核心概念：复古未来主义专辑封面（sweet trip 风格）的完整构图——深靛夜空、霓虹地平线、消失点放射彩虹光束、透视铬网格地板。侧栏扮演封面左半的"夜空"，会话页保持浅色面板可读，主页整面让给专辑艺术。
- 复杂程度：表现型（程序化多层背景构图 + 霓虹辉光 + 克制动效，无 AI 素材、无交互、无组件）
- 语义颜色与字体：
  - 夜空：`#0d0f38 → #1b1e4e → #322f7e → #57449f → #8a5cc0`（垂直渐变到地平线）
  - 地平线霓虹：玫红 `rgba(255,92,210,.6)` → 青蓝 `rgba(120,220,255,.65)`
  - 地板：深靛底 + 青色霓虹网格（`perspective() + rotateX` 真透视）
  - 内容面板：半透明白（会话页 0.84）/ 深靛玻璃（主页 0.45、侧栏 0.78）
  - `--ink #1b1e4e` 浅面主文字；深面上文字由作用域 token 重映射翻亮
  - `--accent #e5007e` 玫红霓虹：发送键、聚焦描边、选中块、选区
  - 彩虹光束色组：`#e63329 #f07c00 #ffd900 #43b02a #2e7fd9 #e5007e`
  - 字体：系统无衬线，标题 800 收紧字距；主页问候白色 + 玫红 text-shadow 辉光
- 标志性元素（均可溯源到参考图/概念）：消失点放射彩虹光束（conic-gradient 硬切条纹）← 封面右半光束；霓虹地平线 + 红蓝色散边 ← 封面天地分界线 + CRT 聚焦不良；透视网格地板 ← 封面下半白色网格大地；侧栏右下角迷你彩条测试卡（SMPTE color bars + 灰阶 + 细扫描线 + 微闪烁）← 彩虹语言的电视测试信号图腾；主页整体 CRT 屏幕质感（四角暗角、RGB 荫罩竖纹、9s 电子束刷新亮带）← 用户指定的 CRT 复古未来电子感
- 背景来源：纯 CSS 程序生成（含 `#kimi-skin-bg::before` 透视地板、`::after` 星点 + 色散边），无图片素材
- 动效强度：克制——光束 26s hue-rotate 呼吸、测试卡 7s 微闪烁、主页 9s 刷新亮带；`prefers-reduced-motion` 全部关闭或静止
- 状态交互：无
- 功能组件：无
- 图片和用户内容如何处理：保持原样，不反相、不遮盖
- 需要覆盖的页面与状态：主页（深色玻璃 + 白色问候）、对话页（浅色面板）、侧栏（深色玻璃 + 亮 token）、定时任务页、插件中心、弹层、滚动区域、hover/focus、窄窗口、reduced-motion
- 本轮明确不做：不使用原图素材、不加 rootStateToggle、不接额度 widget
- 用户确认的设计摘要：v1 为浅色网格方案（2026-08-14 确认）；v2 应用户"要复古未来电子感、更发散"的要求转为封面本体构图（同日实施）；v3 应用户"去撞脸、CRT 化"的要求移除斜切块/彩虹圆盘两处无来源装饰，改为 CRT 屏幕质感与彩条测试卡（2026-08-15 实施）。
