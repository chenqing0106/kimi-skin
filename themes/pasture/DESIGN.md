# Theme design

## 核心概念
青青牧场——清新治愈的田园奶牛主题。蓝天白云下，一只可爱的奶牛在绿色草地上悠闲漫步。双击首页即可切换昼夜，夜晚有萤火虫和星空相伴。

## 语义颜色与字体
- 天空蓝 (#a8d8f0) → 背景
- 草绿色 (#7cb87c) → 辅助元素
- 奶白色 (#fdfcf8) → 主面板底色
- 奶牛灰斑 (#7a8a9a) → 文字与线条
- 粉橘色 (#e89080) → 品牌色/交互点缀
- 字体：系统默认无衬线

## 标志性元素
1. **动态背景**：多层云朵以不同速度缓慢飘动（CSS 动画），底部草地渐变
2. **太阳/月亮**：白天显示太阳，夜晚切换为月亮，颜色过渡平滑
3. **萤火虫**：夜间模式下背景层出现闪烁的萤火虫（CSS 动画）
4. **奶牛眨眼**：侧栏底部小奶牛每 5 秒自动眨眼一次（睁眼↔闭眼切换）
5. **昼夜提示**：鼠标悬停首页时显示"双击切换昼夜"提示

## 交互设计
- **双击首页任意区域**：切换 `html[data-kimi-skin-state="night"]` 状态
  - 白天 → 夜晚：天空变深蓝、月亮出现、星星闪烁、萤火虫飞舞、侧栏奶牛入睡
  - 夜晚 → 白天：恢复明亮色调、太阳出现、云朵继续飘动
  - 所有颜色过渡都有 0.5s 平滑动画

## 背景来源
- CSS 程序生成：多层渐变模拟天空、太阳/月亮、云朵 SVG、草地
- AI 生成素材：奶牛图标（睁眼/睡觉两种表情）

## 图片和用户内容
- 用户图片保持原样，不添加滤镜
- 奶牛图标使用本地 PNG 素材

## 需要覆盖的页面与状态
- 首页（home-view）
- 对话页（conversation-view）
- 侧栏（sidebar）
- 输入框（composer）
- 定时任务页（cron-jobs-page）
- 插件中心（plugins-hub）
- 弹层（dialog）
- 代码块（pre/code）
- 用户气泡（bubble.role-user）

## 本轮明确不做
- 不修改 Kimi 官方功能区域布局
- 不使用 JavaScript
- 不添加远程资源
