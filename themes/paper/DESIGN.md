# Paper · 纸间

## 概念

手工排印的纸质杂志：米白纸底、墨色文字、衬线标题，细黑描边 + 偏移硬阴影的"活版卡片"，朱砂红作为唯一彩色，像印章与红笔批注。

## 颜色与材质

- 纸底 `#f3efe4` / 纸面 `#faf7ee` / 深纸 `#ece6d5` / 墨 `#2a251b` / 灰墨 `#6e6552` / 朱砂 `#b3492e`
- 材质：三层 repeating-linear-gradient 织纹 + 32px 横理（laid lines），纯 CSS 生成，无位图素材（safe-css 校验器不允许 SVG data-URI 内嵌 url(#) 滤镜引用，故弃用 feTurbulence）
- 硬阴影（3–4px 偏移、无模糊）代替弥散阴影，模拟活版印刷的套版感

## 标志元素

- 首页右上角邮票贴图：打孔边（SVG mask）、朱砂双线框与邮戳圆、5° 歪斜、硬投影
- 侧栏 footer 右侧的邮戳环（同心圆，固定在不滚动的 footer 区，不与列表重叠）
- 代码块四角的十字对位规线

## 字体

标题层使用系统衬线（Songti SC / Noto Serif / Georgia），正文与 UI 保持原生字体。无字体文件。

## 内容处理

不处理图片、头像和用户内容；浅色主题不需要反相插图。只覆盖背景、侧栏、面板等结构性表面。

## 交互

无可选交互；不使用 rootStateToggle。

## 不做的范围

- 不生成 AI 位图素材；邮票/邮戳均为矢量
- 不做暗色变体
- Chat 网页界面不在范围内
