# Theme design

- 核心概念：浅色通透的"数字印刷"——近白冰蓝基底上叠半调网点、水彩感青紫色晕和星形几何，Y2K 式的轻盈未来感。
- 复杂程度：完整
- 语义颜色与字体：
  - 基底 `--halftone-ground` #f2fafe（近白冰蓝）
  - 卡片 `--halftone-card` #ffffff
  - 抬升面 `--halftone-raised` #e6f3fb / 深面 `--halftone-deep` #d6eaf8
  - 墨色 `--ink` #23404f（深青灰）、`--ink-soft` #557184、`--ink-faint` #94adbc
  - 主题色 `--cyan` #29b6f6 / `--cyan-deep` #1d8fd1，点缀 `--violet` #7c4dff / `--violet-deep` #5e35d1
  - 字体保持原生，不引入衬线或自定义字体
- 表面层级：根背景（网点 + 色晕）→ 侧栏 #eaf6fd 实色 → 主内容白卡 → 弹层白卡 → 输入框白卡 + 青描边
- 主要材质：半调网点（radial-gradient 程序生成，双密度双层：青 18px 网格 + 紫 11px 网格）
- 标志性元素：首页右上角四芒星 SVG（青色描边 + 紫色错位重影），微光呼吸动效
- 视觉来源映射：
  - 半调网点双层漂移 ← 参考图的 halftone 圆点阵列
  - 青→紫→粉色晕 ← 参考图背景的水彩渐变（青蓝、淡紫、微粉）
  - 四芒星装饰 ← 参考图左侧的青蓝色星形几何
  - 侧栏选中项青紫渐变 ← 参考图整体的青紫双色关系
- 复用范围：只复用 paper 主题已验证的 token 重映射骨架和选择器结构（侧栏、主面板、输入框、插件页、代码块）；配色、网点材质、星形装饰、渐变选中态均为本次原创
- 背景来源：纯 CSS 程序生成，无图片素材
- 动效强度：克制——网点双层缓慢漂移（40s / 28s）、星形微光呼吸（5s）；`prefers-reduced-motion` 下全部停用
- 状态交互：无
- 功能组件：无
- 图片和用户内容如何处理：保持原样（头像、插件图标、用户图片不改）
- 需要覆盖的页面与状态：主页与输入框、会话内容页、用户气泡、代码块、弹层、插件页、定时任务页、侧栏选中/hover、focus-visible、窄窗口、reduced-motion
- 本轮明确不做：暗色模式、rootStateToggle 交互、widget 组件、自定义字体、AI 图片素材
- 用户确认的设计摘要：完整档；背景用 CSS 程序化网点 + 渐变；浅色基调，深青灰文字；克制动效带 reduced-motion 降级；无交互无组件
